# 案件板拖动触发文字搜索

2026-09-15：原生文字选择和图片拖拽与案板指针操作竞争，拖动卡片文字可能选中文字，再次拖动被浏览器解释为搜索。

修复：仅在案板视口内禁止 user-select、原生 dragstart/selectstart/drop，并由 pointer capture 完成拖动。查看模式从卡片、封签、分组标题起拖均平移画面；编辑模式保留卡片和结界移动。表单和详情文字不受该限制。

验证：取消拖动恢复原坐标；拖动文字不产生 selection、不打开详情和新标签页；拖动不误写云端。固定尺寸世界画布改为无边界坐标，连线 SVG 跟随视口，重新进入按实际卡片尺寸全览。须同时检查远处/负坐标保存、全览和浏览器真实渲染。
