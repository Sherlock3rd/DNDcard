# 专长与状态只有显示记录，没有进入角色公式

## 问题

- 预设专长加入角色后只保存名称、说明和自由文本配置，属性提高没有同步到属性卡与派生数值。
- 当前状态只保存字符串，祝福术等持续增益无法修正攻击、豁免、AC、速度或技能。

## 原因

- 展示层和计算层没有共享机器可读的效果定义。
- 专长编辑器只提供自由文本，没有为属性选择建立结构化字段。
- 状态切换只重绘状态标签，没有触发完整角色数值同步。

## 修正规则

1. 可计算的专长和状态必须使用结构化效果字段，说明文字不能充当计算来源。
2. 专长属性选择保存后，必须重算属性、调整值、技能、豁免、先攻、被动值、攻击、伤害与施法数值。
3. 状态添加、移除、长休清除后必须走同一完整同步入口。
4. 骰值修正显示为公式，例如祝福术显示 `+1d4`，不得擅自换算成固定平均值。
5. 数据结构升级必须兼容既有 localStorage key 和旧字符串状态，禁止清空或覆盖用户本地档案。

## 执行前检查项

- [ ] 固定属性专长加入后立即生效。
- [ ] 多选属性专长要求明确选择，保存后生效，移除后回退。
- [ ] 祝福术同步到攻击与豁免，移除后同步撤销。
- [ ] AC、速度、技能与被动值状态分别验证。
- [ ] 刷新页面后专长、状态与原角色存档仍存在。
