# 移动端角色主页入口与状态反馈缺失

## 问题

- 角色页虽然存在返回入口，但手机断点把顶部所有次级按钮统一隐藏，导致“返回主页”不可用。
- 常用状态实际采用即时切换，但弹窗没有明确说明，角色首屏也没有同步反馈，用户会判断为添加失败。

## 原因

- 响应式规则按按钮视觉等级批量隐藏，没有按导航必要性区分按钮职责。
- 状态功能只验证了数据写入，没有验证操作后用户当前视区是否能看见结果。

## 修正规则

1. 主页、返回、关闭等逃生导航不得被通用响应式选择器隐藏。
2. 手机空间不足时优先隐藏重置等低频操作，保留返回主页。
3. 即时生效的预设词条必须明确标注“点击立即添加或移除”。
4. 状态与法术位等战斗资源应在角色首屏提供只读摘要，并与详细操作区使用同一状态源。
5. 回归测试必须覆盖桌面、手机竖屏、手机横屏，以及添加、同步、移除和返回完整链路。
