# 同版本旧缓存遗漏新增字段

2026-09-15 线上验收发现：服务端和 Git 已有棋子 notes，但旧页面的规范化器丢弃未知字段，生成相同 revision 的已同步缓存；新页面仅比较版本，仍显示“暂无备注”。

修复：统一档案对已同步、无冲突且当前未编辑的缓存额外比较规范化内容，同版本缺失字段也从服务器恢复，替换前保留缓存备份。dirty、旧服务器版本、正在编辑和版本冲突仍受原保护；不清理 localStorage，不回写服务器。

防复发：新增字段必须测试同版本旧缓存升级，并更新脚本缓存版本。新增回归覆盖恢复字段、草稿阻止替换与未同步本地编辑保留。运行时公开存档会更新，测试不要假定用户尚未建立任何地点关联。
