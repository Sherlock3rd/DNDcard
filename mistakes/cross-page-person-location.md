# 人物与地图地点保持单一数据来源

地图人物列表通过稳定的 mapPieceId 读取案件板档案，不把头像、职业、等级和坐标重复存入地图。新字段必须贯穿前端规范化器、数据库校验、旧客户端保护和同版本缓存恢复，否则旧页面会无声丢失关联。

创建表单要固定选定棋子，提交前再次检查棋子存在；取消不写入。同名档案必须让用户明确选择。地图移动或改名不修改人物，删除棋子保留人物并显示失效关联。页面跳转只能改变相机和选中状态。

数据库函数修改先检查括号配对，并用回滚事务测试合法值、非法值、缺失字段和显式 null；对比其余字段和模块不变。Supabase MCP 生成的实际迁移版本须与本地文件名对齐。
