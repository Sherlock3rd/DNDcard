# 法术与物品平行交互没有同步

## 问题

法术区已经从“全集页签 + 自定义按钮”重构为“抄录法术”入口，但同类的装备区仍保留旧的“全部物品”页签与“自定义物品”按钮，造成平行功能的交互语法不一致。

## 原因

重构时只验收了当前需求直接点名的法术区，没有把法术与物品作为同一类“角色持有集合 → 全局目录”的模式一起检查。

## 修正规则

1. 角色持有集合的新增入口统一采用动作按钮，进入全局目录后按钮改为“返回”。
2. 角色页不把“加入已有资料”和“创建新资料”混在同一视觉层级。
3. 修改法术书、背包、特性等集合交互时，检查所有同构模块是否需要同步。
4. 角色资源类数据必须同时具备显示、操作、持久化和移动端验收；不能只补静态数值。
