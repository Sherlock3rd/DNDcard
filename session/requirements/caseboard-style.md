# 案件板样式

2026-09-15 用户要求：编辑人物或连线时颜色不应自行变化；允许自由调整样式与颜色，默认保持统一。

- 档案卡底色、边框色、文字色与外框形状可调；连线颜色、粗细与线型可调。
- 调整样式与编辑资料分开，实时预览、取消不写、明确保存、恢复统一默认。
- 保存的样式随既有冒险档案云端同步及Git备份，保留现有人物、关系、位置和结界；不改变角色规则或账户权限。

## 2026-10-11 移动端缩放

- 用户要求案件板在移动端支持正常缩放。
- 单指继续按当前模式拖动画面或编辑对象；双指以中心锚定缩放，并允许随双指中心平移。
- 第二根手指加入时取消并回滚未完成的单指拖动；双指手势只改变当前相机，不写案件板或云端存档。滚轮、按钮、全览与键盘操作继续保留。
- 真实移动端兼容飞书内置浏览器与移动 Safari 的原生 Touch Events，不以桌面 Chrome Pointer Events 模拟作为唯一完成标准。
