# DND 角色卡网页需求会话

## 状态

- 阶段：前置角色入口、规则资料库、角色卡、页面内编辑和升级流程已实现，待真实账户与云端同步。
- 目标：支持登录、车卡、保存记录、读卡和查看当前状态。
- 部署目标：GitHub Pages。

## 已确认

- Git 仓库：`Sherlock3rd/DNDcard`。
- 规则体系来源：Workbencch Rules Bootstrap Spec。
- 需要登录与持久化角色数据。
- 首张卡按 2014 版 5e 构建：Charlie，三级人类预言学派法师，学者背景。
- UI 使用原创生成的 2D 人物、横屏背景、竖屏背景和暗黑奇幻纹理。
- 页面支持横屏、竖屏、触控以及本地状态保存。
- 内置 SRD 5.1 的 319 个法术、237 件常规装备和 362 件魔法物品。
- 角色法术区仅包含“配置法表”和“法术书”：通过“抄录法术”进入全集，按环数准备/卸下法术；移除入口只在详情展开后出现并二次确认。
- 法术资料编辑权只属于法术总览，角色界面不提供法术资料编辑或自定义法术。
- 物品支持背包/全集视图，可直接添加、编辑、删除、调整数量和装备状态。
- 角色可逐级升级至 20 级，并在升级时选择生命成长、新法术、戏法和属性值提升。
- SRD 以外内容使用自定义法术和自定义物品入口添加。
- 在线地址：`https://sherlock3rd.github.io/DNDcard/`。
- 默认入口先选择角色；当前可登录 Charlie，并预留 GPT 创建新角色的位置。
- 入口可前往 12 个基础职业摘要、319 个法术查询、599 件道具查询和图文基础规则。
- 角色入口、职业、法术、道具和规则界面分别使用原创 2D 背景，整体暗黑奥术风格统一。
- 319 个法术与 599 件物品的名称统一显示为“中文（English）”；法术详情纯中文，物品提供中文真实说明。
- 角色卡信息顺序为：属性、战斗、法术、装备、特性、人物。
- 状态管理提供常用 D&D 状态词条快捷开关。
- 所有资料库与规则查看界面一键返回主页，不跳转到单个角色。
- 角色页面本身在桌面与移动端都必须提供清晰可见的“返回主页”入口。
- 角色最前面的总览同步显示当前状态标签和各环剩余法术位；任一处修改后立即同步。
