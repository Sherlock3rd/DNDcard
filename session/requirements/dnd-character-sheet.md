# DND 角色卡网页需求会话

## 状态

- 阶段：前置角色入口、规则资料库、角色卡、页面内编辑和升级流程已实现，待真实账户与云端同步。
- 目标：支持登录、车卡、保存记录、读卡和查看当前状态。
- 部署目标：GitHub Pages。

## 已确认

- Git 仓库：`Sherlock3rd/DNDcard`。
- 规则体系来源：Workbencch Rules Bootstrap Spec。
- 需要登录与持久化角色数据。
- 当前默认卡按 2014 版 5e 构建：甘阿·道夫，三级人类剑咏法师，2014 自定义背景（赌客）；属性为 16/15/14/17/13/6，基础 AC 14，HP 20。剑歌采用塔莎修订版（熟练加值次，长休恢复）。
- UI 使用原创生成的 2D 人物、横屏背景、竖屏背景和暗黑奇幻纹理。
- 页面支持横屏、竖屏、触控以及本地状态保存。
- 内置 SRD 5.1 的 319 个法术、237 件常规装备和 362 件魔法物品。
- 角色法术区仅包含“配置法表”和“法术书”：通过“抄录法术”进入全集，按环数准备/卸下法术；移除入口只在详情展开后出现并二次确认。
- 配置法表默认点击法术时查看详情；只有主动开启“调配模式”后，点击一环及以上法术才快捷准备或卸下，避免浏览时误改法表。
- 法术资料编辑权只属于法术总览，角色界面不提供法术资料编辑或自定义法术。
- 角色装备区只显示“我的背包”和“添加物品”；点击添加进入全物品目录，再次点击返回背包，逻辑与“抄录法术”一致。
- 角色装备区不提供资料编辑或“自定义物品”创建按钮；目录内已有物品可加入背包，背包内可调整数量和装备状态。
- 背包物品的移除入口只在物品说明展开后显示，采用低优先级危险操作并要求二次确认。
- 法术查询与道具查询分别提供统一样式的“添加自定义法术/物品”入口；自定义资料属于全局总览，新建时不会自动写入甘阿·道夫的法术书或背包。
- 钱袋使用 5e 五币制：CP、SP、EP、GP、PP；支持逐枚增减和直接输入，并实时显示折合 GP，不自动改变币种构成。
- 角色可逐级升级至 20 级，并在升级时选择生命成长、新法术、戏法和属性值提升。
- 角色卡提供独立专长显示与设置模块；按 2014 可选专长规则，属性值提升等级可在属性提升与专长之间二选一，专长记录名称、来源、先决条件、效果说明和获得等级。
- SRD 以外的角色专有物品保留在角色数据中，但不在角色页暴露新的自定义创建入口。
- 在线地址：`https://sherlock3rd.github.io/DNDcard/`。
- 默认入口先选择角色；当前可登录甘阿·道夫，并预留 GPT 创建新角色的位置。
- 入口可前往 12 个基础职业摘要、319 个法术查询、599 件道具查询和图文基础规则。
- 角色入口、职业、法术、道具和规则界面分别使用原创 2D 背景，整体暗黑奥术风格统一。
- 319 个法术与 599 件物品的名称统一显示为“中文（English）”；法术详情纯中文，物品提供中文真实说明。
- 法术与物品图标必须按名称、伤害类型、学派或物品类别进行语义映射；角色页与资料库共用同一映射，禁止再按 ID 随机分配图标或改变图标色相。
- 角色卡信息顺序为：属性、战斗、法术、装备、特性、人物。
- 状态管理提供常用 D&D 状态词条快捷开关。
- 所有资料库与规则查看界面一键返回主页，不跳转到单个角色。
- 角色页面本身在桌面与移动端都必须提供清晰可见的“返回主页”入口。
- 角色最前面的总览同步显示当前状态标签和各环剩余法术位；任一处修改后立即同步。
- 专长管理提供 2014 版 5e 的 42 个预设专长目录，支持搜索、分类、规则摘要、一键加入与防重复；需要属性、元素、法术或熟练项选择的专长加入后可继续设置，升级界面复用同一预设数据。

## 待确认

- 登录与云端存储服务选型。
- 单用户私有卡片，还是支持 DM / 队友共享。
