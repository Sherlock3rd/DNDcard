# 冒险日志

2026-09-14 用户授权设计、实现并直接发布。

- 真实日记本视觉，与现有书房 UI 一致；按日期/相对旅程日分章阅读。
- 由用户提供的全团故事转录为甘道夫第一人称亲历记录，保留原文用于核对，不编造日期、奖励或地点坐标。
- 每章一张根据场景生成的图片，参考图的灰金色厚涂环境叙事风格。
- 地点与地图双向关联，地图可定位/绑定棋子，日志可跳转，地图可查关联日期与章节。
- 编辑要本机自动保存，登录后自动提交账号云端；取消不得写入，断网可恢复，冲突保留副本。
- 首篇《余烬与旗帜》五章；“铁环镇 / 石栏镇”名称不一致已提问，未确认前使用矿业小镇并保留原文。

实现与验收详见 `docs/adventure-journal.md`。
