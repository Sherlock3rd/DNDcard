# 黑塔统一导航

用户要求：书房、案件板、地图桌、人物同级，可用图标展示；页面功能按钮独立为第二层，集中在右下角。

实现：共享顶部导航使用线性SVG图标与短名称，aria-current标记当前页面，手机保留全部四项。书房与人物沿用原hash路由；案板与地图沿用现有页面地址。

右下角：案板保留编辑/全览，地图保留移动模式/整图，人物保留升级；其余操作进入向上展开的工具面板。书房工具提供书架设置与日记。页面内针对单个人物、棋子或角色资源的操作继续留在对象附近。

只搬移现有控件，保留ID、事件和存档。地图对照图层在面板内部展开，短屏与手机可滚动。工具支持点击空白收起和Esc收起；角色未完成档案加载时，搬移后的升级入口仍受保护。

验收：57项测试通过；实际浏览器覆盖四页入口、人物与书房切换、案板编辑工具、地图图层展开、手机390×844导航无缺失与无横向溢出。
