# 地图桌试用版发布

2026-09-14，用户明确授权发布地图桌。

- 正式入口：书房地图桌 → `map.html`，带返回书房链接。
- 13款实体棋子：城堡/边境哨塔/山地要塞；村落/风车农庄/渔港；矿井/伐木营地/晶石矿脉；事件旗标/战场遗迹/宝藏；当前位置。
- 8款新增素材均为1254×1254 RGBA，alpha范围0–255；与已有深木黄铜底座风格一致。选择分类时按需请求，没有进入地图就加载全部新增素材。
- 保留小尺寸、双倍落点阴影、当前位置居中近景、移动模式与信息栏编辑/删除流程。
- 正式页仅预置当前位置，不预放示例城堡等。初次发布遗漏存档，现已补上本机自动保存与账号云同步，见 map-autosave.md。事件记录与人物关联尚未接入，OCR候选仍待校对。
- 全套 npm test 通过（目录审计、设置/编辑/存档安全、13项云同步与书房测试）；10项地图发布/LOD/裁剪/阻尼测试通过。浏览器验证新增哨塔可选可放、透明显示。
- 使用独立发布worktree，仅纳入地图相关文件及用户已要求的主页HUD下方导览移除；不覆盖当前目录其他修改和玩家存档。
