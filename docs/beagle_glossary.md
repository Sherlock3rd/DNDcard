# DNDcard 项目术语表

> 文件名沿用 Rules Bootstrap Spec 的标准交付物；本项目内容用于 D&D 术语。

| 术语 | 定义 | 使用场景 |
| --- | --- | --- |
| 角色卡 | 记录角色属性、职业、生命值、资源、装备、法术等信息的数据对象 | 创建、保存、读取角色 |
| 车卡 | 按规则创建新角色的过程 | 新角色向导 |
| 当前状态 | 角色在游戏过程中的生命值、临时生命、资源、法术位与状态效果 | 实时查看与更新 |
| 读卡 | 从持久化存储加载已有角色数据 | 登录后查看角色 |
| 规则版本 | 角色计算与可选内容所遵循的 D&D 5e 规则版本 | 2014 / 2024 规则口径 |
| 法术总览 | 独立于角色的全局法术资料库，也是唯一允许修改法术资料的界面 | 查询与维护法术名称、规则文本和职业归属 |
| 角色法术书 | 某个角色已经学会或抄录的法术集合，不负责修改法术规则资料 | 抄录、查看详情、移除 |
| 配置法表 | 从角色法术书中选择当天准备法术的操作界面；戏法不占准备栏位 | 按环数点击准备或卸下法术 |
