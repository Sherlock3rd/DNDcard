# 地图与日记全屏、棋子备注

2026-09-15，用户授权：地图与日记适配全屏，防止拖动/滚动丢失信息；特殊棋子在重叠时置顶；棋子增加可预览和编辑的备注，填入铁环镇示例。

## 使用

- 两页默认铺满当前窗口，工具栏、保存状态和日记翻页入口留在可视区域。全屏按钮支持浏览器全屏；不可用时进入铺满窗口的专注布局。
- 地图信息栏固定标题、关闭及编辑/移动/删除入口，正文单独滚动；棋子匣按可用高度滚动。同一时间只展开一个地图侧栏。
- 日记桌面双页各自滚动；窄屏改为连续单列书页，外层翻页按钮固定可见。
- 改变窗口或进出全屏保持地图中心与缩放，不重置到当前位置；缩放规则和玩家坐标不变。
- 特殊类别当前位置棋子 z-index 20，高于普通及拖动棋子；侧栏仍在棋子之上。
- 点击棋子预览地点备注，点击编辑填写，保存时与名称一起提交；取消不保存。支持换行，最多 4000 字符，按纯文本显示。

## 存档兼容

地图棋子增加可选字符串 notes，沿用原统一档案的本地保护、自动同步、版本冲突、历史及 Git 回传。字段缺省与空字符串区别保留。服务端按稳定棋子 ID 合并旧客户端遗漏的 notes，显式空字符串才能清除，避免旧页面移动或改名丢失新备注。
