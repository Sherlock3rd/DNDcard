2026-09-14，用户要求真实日记本的感觉、按日记录、由全团文本转录为甘道夫第一人称、每章生成参考图风格插画、地点关联地图并直接发布。

正式入口为书房桌上的“冒险日记”，独立页面 `journal.html`；书房、日志与地图互通。首篇《余烬与旗帜》五章，保留七名主队成员、五名被招揽的强盗、一车两马、五百枚团队金币及废堡易主等事实。不增加角色金币、不自动改人物关系、人物种族、装备、等级或日历年代。

原文既称铁环镇也称石栏镇，已提出名称确认。尚无答复时正文以“矿业小镇”指代，原文夹页保留原始措辞；不是擅自确认别名关系。日期使用“出奔前夕”“出奔之日”“又行半日”“夺堡之日”等原文相对时间。两者均可待后续团录校对。

- 深木桌面、皮革封边、泛黄纸页、书脊明暗、页码与暗红书签，颜色承接黑塔书房。
- 左页为场景画、摘句、地点和人物；右页为日期、章名、第一人称正文与签名。原始全团文本折叠在“夹页”。插画属于日志画面，不表示角色外貌已定稿。
- 上一章/下一章、方向键、可收起篇目目录与稳定章节 URL；默认翻开第一章，不先加封面阻挡。
- “补记 / 编辑”修改名称、日期、正文与地点；“续写一页”新增手记。取消/关闭/Esc 不修改已保存正文；提交后立即本机保存并排队云同步。新章可填既有素材或 HTTPS 配图地址。
- 转录与场景生成由本次助手工作完成，网页没有假冒的在线 AI 转录接口。下一次提供团录后，继续按“核对事实 → 第一人称转录 → 每章配图 → 更新日志”处理。

## 插画

五章各有一张 1536×1024 原生插画，内置 image_gen 生成，灰金/灰褐低饱和厚涂、环境叙事为主。第二章补齐第七名同行者，第三章校正七名队员与五名强盗。文件位于 `assets/images/journal/`，完整提示词见 `journal-image-prompts.json`。

每次只加载当前章节图片，不预载五张大图；既有地图后台 LOD 渲染保持独立。图片总量约 15 MB，不随每次存档上传，云端只保存素材路径、文本和地点关系。

## 地图关联

2026-09-15：日记的每个“沿途记号”旁新增“关联棋子 / 更换关联”。弹窗按地图棋子的名称或类型搜索，选中后确认关联；刷新与取消不写日志。保留日记地点原称呼、说明和章节正文，多个不同地点 ID 可以关联同一棋子 ID，不新建或重命名地图棋子。引用同一个日记地点的所有章节共享该关联。

候选来自最新完整档案中的地图部分，也识别本机尚未上传的地图修改；提交前再次读取并检查目标仍存在。关联窗口打开时暂停外部日志快照替换，提交走原有 journal:change 与统一自动同步/Git 备份。解除关联保留最后坐标，不删除地图棋子。已有关联显示棋子名称，目标已删除时提示重新选择。

验证：14项日志与统一存档页面测试通过，覆盖异名同址、两地点关联同一棋子、取消无写入、选择中目标被删、跨设备恢复、解除关联保留其他引用，以及原有跟随移动/双向日志链接。本机浏览器已从实际存档搜索到凡息之堡；未替用户预先确认地点对应关系。

日志地点使用稳定 ID；博德之门落点沿用原地图已核对坐标 `(1036,1157)`。荒野路段、小镇和废堡只有叙事方位，默认未落点，禁止伪造官方精确地理位置。

点击地点进入地图的“日志地点”面板，列出日期和关联章节，点击即可翻回。可以直接选地图落点，或绑定已放置的实体棋子；绑定后跟随该棋子的移动。移除棋子时保留日志地点最后坐标并解除绑定。清除日志落点需界面确认，不删除正文或地图棋子。地图上的独立日志地点使用已有实体棋子美术，已绑定地点不重复叠放一个标记。

## 本机与服务器

独立缓存 `dndcard-journal-v1:` 与 Supabase `journal_saves`、`journal_save_history`、`save_journal`，沿用书房账号和本人私有 RLS。迁移版本 `20260914142214_create_private_journal_sync` 与线上一致。

首次打开即可读到已发布的五章；登录已有书房账号且云端无日志时自动建立初始存档。后续编辑约一秒上传，断网保留待上传快照；版本检查和冲突备份保护不同设备的修改。地图与日志共享认证客户端，内容仍使用各自存档。切换账号时若尚有打开的编辑器则暂停切换，先完成/取消，防止把旧账号草稿写入新账号。
