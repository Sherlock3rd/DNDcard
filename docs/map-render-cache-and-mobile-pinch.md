# 地图渲染缓存与案件板移动端缩放

2026-10-11，地图桌新增持久渲染缓存，案件板新增移动端双指缩放。

地图仍保留页面内 48 块内存 LRU；新增 IndexedDB `dndcard-map-render-cache`，最多保留 96 个 overview / detail PNG Blob。缓存键由地形源哈希、城市与奇观、源标记和缓存格式共同计算；任何视觉输入变化都会自动换键。IndexedDB 不可用、配额不足或读取损坏时，不阻断地图，继续走原来的 Worker 实时绘制。

案件板双指手势同时完成缩放和平移，锚定两指中心对应的世界坐标。第二根手指加入会回滚尚未完成的卡片、结界或画面单指拖动；结束手势不产生 `board:change`，不修改人物、连线、结界或云端版本。滚轮、缩放按钮、全览和键盘导航保持不变。

验收：40 项地图、案件板与档案相关回归通过。Chrome 390×844 真实触控模拟中，案件板从 `scale(0.206856)` 双指缩放至 `scale(0.369387)`，同时发生中心平移，页面无横向溢出、存档写入为 0、运行时异常为 0。地图首次进入为缓存 miss；同浏览器刷新后 overview 与 8 个可见分块均命中持久缓存，区域 JSON 重绘缓存占用从 12 降为 0，首批细节完成时间从约 1123ms 降至约 645ms。该时间仅代表本机本轮，不承诺所有设备相同。
