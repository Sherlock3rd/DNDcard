# 规则引导规范（Rules Bootstrap Spec）

## 目标

- 在任意新项目中快速建立“规则—会话—错题—复用”四位一体的执行体系。
- 仅需确认用户角色与助手角色；已有全局默认且适配项目时无需重复询问。

## 标准交付物

- `rules/rules.md`：基础规则与对话规范。
- `session/session.md`：总控会话与提交总账。
- `session/requirements/<doc_slug>.md`：需求级状态与修改记录。
- `mistakes/`：错题记录与归纳。
- `spec/rules-bootstrap-spec.md`：本规范。
- `docs/beagle_glossary.md`：项目术语表与关键流程索引。

## 执行步骤

1. 使用全局默认角色；仅在明显不适配且会影响结果时确认。
2. 建立规则、会话、错题、规范与术语目录。
3. 将执行原则、错误处理和更新流程写入项目规则。
4. 初始化全局状态、需求级会话、错题模板和术语表。
5. 所有规则自创建起生效；新增规则时同步维护规则与会话记录。

## 通用执行原则

- 明确简洁执行；未经允许不得修改设计。
- 对会实质改变设计结果的不确定问题必须确认。
- 错误必须记录，并将同类错误归纳为执行前检查项。
- 用户新增或调整规则时，必须同步维护项目规则。
- 设计相关变更须先获得书面确认；非设计脚手架可直接执行，但必须记录。
