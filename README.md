# DNDcard

基于 2014 版 D&D 5e 规则的响应式角色卡网页。目前内置三级人类预言学派法师 Charlie，支持：

- 完整属性、技能、豁免、战斗数据、种族/职业/背景特性
- SRD 5.1 全量目录：319 个法术、237 件常规装备、362 件魔法物品
- 法术书、已准备法术、法术筛选和法术资料的页面内增删改
- 背包、数量、装备状态、负重和物品资料的页面内增删改
- 1–20 级法师升级流程：生命成长、新法术、戏法、属性值提升和法术位
- 为法术与物品提供统一风格、稳定映射的原创 2D 图标
- 当前生命、临时生命、法术位、预兆骰与状态管理
- 浏览器本地持久化
- 桌面、平板、手机横屏与竖屏适配

直接打开 `index.html` 即可预览。

规则数据来源与许可见 `ATTRIBUTION.md`。SRD 以外的自有、第三方或自制内容可通过页面内的自定义法术/物品编辑器添加。
