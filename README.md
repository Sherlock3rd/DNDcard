# DNDcard

基于 2014 版 D&D 5e SRD 5.1 规则的响应式角色卡网页。目前内置三级龙裔剑咏法师甘阿·道夫，支持：

- 前置角色档案入口与角色选择；后续可扩展 GPT 生成的新角色
- 独立职业规则大厅、法术总览、道具总览和基础规则图文教程
- 属性、技能、豁免、战斗数据、种族/职业/背景特性与人物资料
- 319 个法术和 599 件物品的中英双语目录，名称格式为“中文（English）”
- 中文法术详情、真实物品说明，以及统一风格的原创 2D 图标
- 参考《博德之门 3》信息层级的法术准备栏：按环数展示、点击准备或卸下
- 角色法术书抄录、详情内移除与二次确认；全局法术资料在法术总览中编辑
- 背包物品添加、数量、装备状态、负重和详情查看；移除操作位于详情内并带二次确认
- 法术与道具总览支持创建自定义资料，并与角色法术书、背包的持有操作分离
- 与抄录法术同构的“添加物品”目录流程，以及可增减、直输和实时换算的五币制钱袋账本
- 1–20 级法师升级流程：生命成长、新法术、戏法、属性值提升和法术位
- 当前生命、临时生命、法术位、塔莎修订版剑歌次数和常用状态词条管理；剑歌开启时实时联动 AC、速度、杂技优势与专注豁免
- 角色首屏实时状态标签与简易法术位摘要，和战斗资源双向同步
- 角色页桌面与移动端均可直接返回角色主页
- 浏览器本地持久化
- 桌面、平板、手机横屏与竖屏适配

直接打开 `index.html` 即可从角色入口开始预览。在线版本：
`https://sherlock3rd.github.io/DNDcard/`

规则数据、中文文本来源与许可见 `ATTRIBUTION.md`。中文文本为非官方版本，实际规则裁定应以 SRD 5.1 英文原文为准。
